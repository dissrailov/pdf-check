# PDF Check

Проверка макетов (PDF) перед печатью по размерам из ТЗ: размер, масштаб, разрешение картинок, шрифты, цвет.

## Скачать

Готовый `PDFCheck.exe` лежит на странице **Releases** (релиз `latest`). Python не нужен.

## Запуск из исходников

Нужен Python 3. Двойной клик по `start.bat`, подробности в `README.txt`.

## Сборка

При каждом изменении в ветке `main` GitHub Actions собирает `PDFCheck.exe` и обновляет релиз `latest`.
