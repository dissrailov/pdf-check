PDF Check: проверка макетов перед печатью

ЗАПУСК
1. Нужен Python 3 (python.org, при установке отметить "Add python.exe to PATH").
2. Двойной клик по start.bat. При первом запуске он сам поставит нужные библиотеки
   (PyMuPDF, customtkinter, tkinterdnd2).
   На start.bat можно сразу бросить PDF-файлы или папку.

КАК ПОЛЬЗОВАТЬСЯ
1. Слева впишите размеры из ТЗ: одна строка на позицию.
   Поля: название (по желанию), ширина, высота, количество (по желанию).
   Выберите, в чём размеры: см или мм. Enter добавляет новую строку.
   Если ТЗ пришло текстом, нажмите "Вставить списком" и вставьте его целиком:
      Л1 верх 110x110
      Л3 110 × 218 см
      Баннер 1100*2180 мм 6 шт
2. Добавьте PDF кнопкой или перетащите файлы/папку в окно.
3. Каждая карточка: один макет. Зелёная метка: готов, жёлтая: проверить,
   красная: ошибка. Причины видны сразу, клик по карточке раскрывает все проверки.
   Справа вверху фильтр по статусу.

КАК ФАЙЛ ПРИВЯЗЫВАЕТСЯ К ПОЗИЦИИ ТЗ
- Если в имени файла есть название позиции (Л1_верх.pdf -> "Л1 верх"), размер
  сверяется именно с ней.
- Иначе позиция подбирается по размеру страницы.
- Масштаб (1:1, 1:2, 1:5, 1:10 ...) определяется сам, если стоит "Авто".
- Над списком показано, для каких позиций ТЗ макетов ещё нет.

НАСТРОЙКИ
- Расстояние просмотра: от него считается нужное разрешение.
- Остальное в "Дополнительных настройках".
- Свой порог, ppi: если типография дала конкретную цифру, она важнее расстояния.
- Допуск по размеру: на сколько мм макет может отличаться от ТЗ.
- Припуск на сторону: если к размеру ТЗ добавляются поля под подгиб/люверсы.

СБОРКА .EXE (чтобы работало без Python)
Запустите build_exe.bat, готовый файл появится в dist\PDFCheck.exe.
